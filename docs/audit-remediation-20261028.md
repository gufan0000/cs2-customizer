# 2026-10-28 审查修复的兼容边界

本批解决文件覆盖与撤销、图标成组提交、配置重载与导入、音频退出、失败重试、崩溃日志脱敏、键盘和辅助技术等确认问题。保留现有配置格式、界面布局和进程归属规则，不重写音频/GSI 架构。

代码行数台账按本批实际值登记，不留增长余量，不减少计数范围。新增内容主要是同目录原子替换、失败回滚、任务取消和控件状态同步；为减行而删除这些路径会重新引入已复现的问题。X1 对应主窗重载和账号任务收尾，X2 对应开关与设置行，X3 对应配置写入和输入校验。

契约快照的变化有明确来源：X6 的 `audio_manager` 被新故障注入测试引用；X7 的 `KILL_LEVELS`、`_collect_incomplete_kill_styles` 是已有资源检查测试的依赖，`stop_audio_tasks` 是已有退出清理的依赖。更新的是被调用名称账目，没有删除旧条目或声称这些静态快照完成了真实游戏验收。

自绘开关改为继承原生 QCheckBox 以提供键盘和辅助状态，仍使用原来的绘制与命名。界面扫描测试须区分总开关与它支配的内容控件；图标页控件计数增加 1，是同一个已有开关现在进入 QCheckBox 扫描范围，没有新增一项设置。

配置恢复不再通过控件变化触发保存。预览测试明确设置初始动画，避免依赖旧的加载副作用。重置从删除文件改为原子写入空配置，仍必须先建立快照，再更改配置，并保证退出保存不能还原旧值。

回退验证的图标裁边断点随逐帧内存复用更新，继续模拟逐帧独立裁剪导致动画抖动。新增 AUD28 组直接重新引入覆盖、误撤销、回滚丢失、重载回写、解码预算缺失、关闭后补发和重置被覆盖等缺陷，要求相应行为测试报错。

运行边界：所有本地验收使用隔离配置及假音频/输入。真实 CS2、实际声音、麦克风、窗口焦点和安装包验收须另行安排。性能对照为合成图像路径，不宣称整机总性能或所有用户场景的同等增益。
