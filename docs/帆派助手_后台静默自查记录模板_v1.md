# 帆派助手后台静默自查记录模板 v1

## 1. 文档定位

本文档是后台静默自查的“落地记录页”。

用途不是定义规则，而是让我在每次检查后能稳定留下结构化结果，避免：

- 只记得“查过了”，却说不清查了什么
- 只说“没问题”，却拿不出证据
- 下次回头看时，不知道上次到底覆盖到了哪里

## 2. 使用规则

每次后台静默自查完成后，至少要形成一份这样的记录。

可以有两种形式：

- 直接按这个模板在最终汇报里输出
- 或者先在临时记录中填完，再压缩成对你的汇报

最低要求：

- 不得省略“覆盖范围”
- 不得省略“已执行命令”
- 不得省略“截图目录”
- 不得省略“残余风险”

## 6. 不合格记录示例

下面这些写法都不合格：

### 6.1 只有结论，没有证据

```markdown
我看了，没问题。
```

### 6.2 只有命令，没有覆盖范围

```markdown
pytest 过了。
```

### 6.3 只有截图，没有判定

```markdown
截图我抓了几张。
```

### 6.4 只说“没问题”，不说没检查到什么

```markdown
都 OK。
```

## 7. 最终定义

以后我按后台静默规范检查完后，至少要留下能复盘的结果记录。

如果没有形成这样的记录，就说明这次检查还不算真正完成。
