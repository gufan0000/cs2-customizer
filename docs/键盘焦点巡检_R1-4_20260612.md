## 结论与决策

1. **焦点链完整性全部通过**:六页所有可聚焦控件都在 Tab 链上,键盘可遍历。
2. "错位"是**几何阅读序启发式**的报警:Qt 默认按创建序(=卡片内聚)走焦点,
   多列布局下与"严格从上到下"必然交错——这未必是坏体验(卡片内聚优于跨列跳跃)。
3. **刻意不做**盲目的 setTabOrder 重排:离屏环境无法验证真实键盘手感,
   重排有把"卡片内聚"改坏的风险。留待真机键盘抽验后,仅对确认别扭的页逐页修。
4. 巡检中发现并修复一个真冲突:全局快捷键 Ctrl+1..4 与音板槽位 ctrl+数字
   全局热键双触发 → 改为 Alt+1..4。
