# CS2 Customizer 后台静默自查索引 v1

## 1. 文档定位

这份文档是后台静默自查资产的总入口。

它只回答两个问题：

- 以后我做完工作后，默认该先看哪份文档？
- 不同规模的改动，应该按什么顺序使用这些文档？

这不是规则细则，也不是记录页，而是“导航页”。

## 3. 默认使用顺序

以后我做后台静默自查时，默认使用顺序固定为：

1. 先看 [CS2Customizer_后台静默自查规范_v1.md](./CS2Customizer_后台静默自查规范_v1.md)
   - 确认这次必须查什么、什么不能做、什么算通过。
2. 再看 [CS2Customizer_后台静默自查覆盖矩阵_v1.md](./CS2Customizer_后台静默自查覆盖矩阵_v1.md)
   - 确认这次要重点覆盖哪些页面和风险点。
3. 执行时按 [CS2Customizer_后台静默自查执行模板_v1.md](./CS2Customizer_后台静默自查执行模板_v1.md)
   - 确认具体顺序和最小动作。
4. 汇总时按 [CS2Customizer_后台静默自查记录模板_v1.md](./CS2Customizer_后台静默自查记录模板_v1.md)
   - 留存证据和结果。
5. 如果发现问题，再查 [CS2Customizer_后台静默自查常见失败处理手册_v1.md](./CS2Customizer_后台静默自查常见失败处理手册_v1.md)
   - 决定怎么修、怎么回归、怎么避免扩大范围。

## 5. 执行主体

这套资产默认不是给你手动逐页点检查用的，而是给我执行的。

也就是说：

- 默认由我在完成改动后主动做后台静默自查
- 默认由我整理测试结果、截图和结论
- 默认由我判断这轮是 `PASS / SOFT FAIL / HARD FAIL`

如果你没有特别要求，这套文档的执行主体始终是“我”，不是你。
